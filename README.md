# Plasma Slate

Turn an Android tablet into a real, touch-enabled extra monitor for **KDE Plasma (Wayland)**.

- The tablet shows up as a normal monitor in *System Settings → Display & Monitor* — arrange it anywhere.
- Your mouse moves across onto it; windows drag between screens.
- Touch on the tablet works independently of the mouse cursor.
- Linux runs the server (`slated`), the Android app is the client. Network first; USB later.
